# E-Commerce SQL Data Analysis

## Objective

Use SQL to extract, manipulate, and analyze e-commerce data using MySQL.

## Tools Used

- MySQL
- MySQL Workbench
- GitHub

## Database Tables

- Customers
- Products
- Orders
- Order Items

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- Views
- Indexes
- EXPLAIN

## Analysis Performed

1. Filtered and sorted products by price.
2. Calculated average product prices by category.
3. Calculated total stock by category.
4. Joined customers with their orders.
5. Analyzed customer spending.
6. Used subqueries to identify customers with above-average orders.
7. Created a customer sales view.
8. Created an index and used EXPLAIN for query optimization.

## Project Outcome

This project demonstrates practical SQL skills for data analysis, including data retrieval, aggregation, joins, subqueries, views, and basic query optimization.
